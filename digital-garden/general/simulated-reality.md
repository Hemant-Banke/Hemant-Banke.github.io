[[Rick&Morty Infinite Worlds]]

The importance of creating a world model, that is identical to our world is crucial to us. If we create such a model, it will have to be completely identical to ours, with no way to distinguish one from the other. It must have an entire simulated universe, left unexplored, much like ours. It must have the diversity and the elements crucial for carbon life to exist. And life must emerge, not programmed to exist. \
A world like that should then also have the ability to assemble life like ours, and a species identical to humans. We must make this `universe` large enough so that the infinitesimal probability of our existence becomes large enough to realize. \
A species like that must also have made the same technological advancements and must have the same thoughts as we do. It would realize the importance of such a model as well. If we were able to build it, this specie must be able to build it as-well, for the same purpose. This recursive loop has no end, and no beginning. 

We can be in a child world, one of the children worlds, or the one root `real` world. The creation of exact model would suggest there is no way to find out. If the model is finite though, we must hit a wall doing something that was not important to model, or is a limit set by the simulator. 

The simulator will not stop by creating only one world, but can be running experiments in parallel, just like we would. For the interesting experiments to survive and be studied further. \
This suggests the best way to live is to do interesting things. [[Truman Show]], [[The 8 Show]]. 

Perhaps the reason of this simulation is to study something totally different, something non-human, or some aggregate behavior, and we happen to exists in the grand nature of this world. 

## What would root reality look like
Creating a world model that matches our reality would be the first step. Many such models can be used to run parallel tests for everything we need. \
If we can create worlds at will, curiosity will drive us into also exploring other worlds. Can changing some parameters, some configurations, lead to better worlds. Perhaps study on impact or behavior of life across different universes. A Study on different kinds of possible life forms. Can a different universe create a `better` and more intelligent species, compared to some threshold. Or just studying rocks in different universes. Or for mining a mineral that will prove to be useful to us. \
In the grand universe that must be created, we might not be the subject in study either. We haven't explored any intelligent life form in our universe yet. So the simulator's root reality can be totally different.
